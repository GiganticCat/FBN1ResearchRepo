| PyRosetta | 2026.30+release.bc091c65b8 (built 2026-07-23) | `.venv-rosetta` (Python 3.11.15 via uv) |

No licence registration is required: the installer resolves to an open URL
(`https://:@west.rosettacommons.org/pyrosetta/release/release/PyRosetta4.Release.python311.ubuntu.wheel/`)
and `LICENSE.PyRosetta.md` ships inside the package.

Two install notes, both of which otherwise fail silently (exit 0 when piped through `tail`):
`uv venv` provides no `pip`, so `pyrosetta_installer.install_pyrosetta()` falls back to the
system interpreter and dies on PEP 668 — install the wheel URL directly with
`uv pip install --python .venv-rosetta/bin/python <url>`; and uv rejects that wheel because its
internal version (`2026.30+release...`) disagrees with its filename (`pyrosetta-0`), so
`UV_SKIP_WHEEL_FILENAME_CHECK=1` is required. The project venv is Python 3.14, for which no
PyRosetta wheel exists, so the separate 3.11 environment is mandatory rather than stylistic.
